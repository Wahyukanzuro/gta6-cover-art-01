Turn a photo and a caption into GTA 6-style cover art: a multi-panel poster with bold gradient lettering and a Vice City sunset-and-neon grade, exported as a PNG you can share.

Open `app/index.html` in a desktop browser. Pick a photo — it is loaded on your own machine and never leaves it — crop and position it across the panels, edit the caption, choose a grade and a layout, then export a cover in 1080x1080, 1080x1350, or 1920x1080.

Built for the [make.fun bounty](https://make.fun/bounty/gta6-cover-art-01).
